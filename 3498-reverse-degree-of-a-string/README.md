# 3498. Reverse Degree of a String

**Difficulty:** Easy

## Problem

Given a string `s`, calculate its reverse degree.

The reverse degree is calculated by multiplying the position of each character in the reversed alphabet (`a = 26, b = 25, ..., z = 1`) by its position in the string (1-indexed).

Return the sum of all these products.
